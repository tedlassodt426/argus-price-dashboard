Argus 煤炭价格拉取工具使用说明
==============================

第一步：填账号密码
  用记事本打开 config.ini
  把 username 和 password 换成你们的 Argus Direct 登录账号密码，保存。

第二步：拉取价格
  双击 拉取煤价.bat —— 拉取今天的价格，自动对比前一日涨跌。
  结果保存在 argus_output\煤价\ 文件夹，文件名类似 煤价_2026-08-07.csv，
  用 Excel / WPS 直接打开。

可选操作（在脚本文件夹地址栏输入 cmd 回车后执行）：
  python argus_coal_fetch.py --date 2026-08-07    拉取指定日期
  python argus_coal_fetch.py --no-change          不对比前一日（更快）

关于价格清单（codes.csv）：
  工具按 codes.csv 里的编号对照表筛选煤炭价格（API 2、API 4、纽卡斯尔、
  理查兹湾、汉普顿路、秦皇岛等，含日度和周均价）。
  如需增删价格，用记事本打开 codes.csv，按行编辑"编号,价格类型,时间戳,名称,类型"。
  新增编号的方法：先运行 python argus_fetch_day.py --date 日期 拉取全天数据，
  把 argus_output\days\ 里的 CSV 和当天 PDF 对照找出编号。

常见问题：
  1. 提示账号密码错误：检查 config.ini。
  2. 提示"当天无报价"：周六日或休市日属正常，周一会补上。
  3. 涨跌列为空：前一日休市或该价格为周均价（周均价每周更新，无日度涨跌）。

账号密码只保存在你自己电脑的 config.ini 里。

Argus 助手（手机版）使用说明
=================================

这是什么：
  一个手机也能用的 Argus 小助手，三个功能页：
    1. 价格台：所有价格可勾选搭建自己的价格台，看趋势、看价差、按年月日查轨迹
    2. 新闻：搜 Argus 新闻（需要账号开通新闻接口后可用）
    3. AI：跳转 Argus 官方 Ask Argus（网页版/手机 App）

价格台使用：
  「添加价格」：从全部 184 项价格里勾选（煤炭 42 项已命名，其他可自行改名），
    点"保存价格台"后回到「我的台」看最新价格和涨跌。
  「趋势」：选时间范围（7天/30天/90天/1年/自定义），勾选要看的价格，出折线图和表格。
  「价差」：选两个价格，自动算价差（A−B）并画走势。
  周指数（ICI、API 周度）每周五更新；日度价格每天更新。

界面设置：
  右上角「🎨 主题」按钮：牛皮纸 / 淡绿 / 深色 三种背景随意切换，刷新后仍保持。
  打开任一份日报后，右上角出现「📖 阅读设置」按钮：
    字号（A−/A+，12–24 号）、字体（默认/宋体/楷体）、行距（紧凑/标准/宽松）、
    段落间距（小/中/大），设置自动保存。

价格目录说明（price_catalog.csv）：
  由 build_catalog.py 根据参考日数据生成；想加新价格、改名称，
  用记事本编辑 price_catalog.csv 后重启助手即可。

第一步：本机使用
  双击 启动Argus助手.bat
  会自动打开 http://127.0.0.1:8768
  访问密码在 app_password.txt 里（首次启动自动生成，启动窗口也会显示）
  注意：启动Argus助手.bat 和 启动手机版助手.bat 二选一，不要同时双击

第二步：手机使用
  双击 启动手机版助手.bat
  等待 20-60 秒，窗口里出现 https://xxx.trycloudflare.com 网址
  手机（用流量也行）打开该网址，输入密码即可使用
  注意：电脑、助手、隧道窗口都要保持运行，网址每次启动都会变

关于日报：
  "日报"页直接读取电脑上 D:\ArgusPublications 里已自动下载的 Argus 日报：
  - Coal Daily International（国际煤炭日报，每天）
  - Indonesian Coal Index（印尼煤价指数，每周五）
  - McCloskey Coal Price Index（煤炭价格指数，每周五）
  新闻文字识别支持两种引擎：
  - Umi-OCR（默认，推荐）：Windows 离线 OCR 软件，自带 PaddleOCR 引擎，
    质量好、速度快。需要先启动 Umi-OCR（双击《启动Argus助手(含Umi-OCR).bat》
    会连 Umi-OCR 一起启动）。
  - RapidOCR（备用，本地轻量）：Umi-OCR 没启动时自动回退使用。
  - Unlimited-OCR（可选，远程 GPU）：百度开源文档解析大模型，
    需要一台 NVIDIA GPU 机器部署服务。方法见《部署Unlimited-OCR服务.md》，
    部署后把 config.ini 的 [OCR] 段 backend 改成 unlimited 并填 url。
  日报标题旁会显示"识别：Umi-OCR（Paddle）"即表示正在用 Umi-OCR 引擎。
  打开日报后有两个页签：
  「新闻」：按标题自动切成一条条新闻卡片（中文标题 + 中文正文），
    勾选"显示英文原文"可看英文标题和原文；首次翻译较慢（CDI 约 1-2 分钟），
    之后秒开；新一天的 PDF 下载后自动出现。
  「价格表（原图）」：把日报里的价格表格原样渲染成图片，整页的按整页显示，
    夹在新闻中间的表格自动裁出表格区域，点击图片可放大查看原图。

关于 AI：
  Argus 的 Ask Argus 没有开放第三方接口，只能用它官方渠道：
  - 网页版：Argus Direct 登录后使用
  - 手机 App：官方 Argus App（App Store / 应用商店搜索 "Argus"）
  助手 AI 页有直接跳转按钮。

关于"小程序"：
  真正的微信小程序需要备案域名+小程序账号+接口白名单，门槛较高。
  目前这个手机版网页（把网址存到手机主屏幕）效果最接近，先这样用；
  如果单位有备案域名，后续可以改造成正式小程序。

新增功能（2026-08-16）
=================================

一、MCC（McCloskey）M42 周度指数自动下载
  - 每周五 17:30 / 18:30 / 19:30 计划任务自动抓取 mccloskey.opisnet.com 最新一期
    "Indonesian FOB Markers"，提取 M42（印尼 4,200 GAR FOB，周）并写入看板。
  - 数据文件：argus_api\argus_output\mcc_m42_weekly_series.csv
    （opis_api\opis_output\mccloskey_m42_weekly_series.csv 为全量序列）
  - 手动立即更新：双击 opis_api 里的"更新MCC-M42.bat"，或运行
    python opis_api\mccloskey_update.py
  - 计划任务名：MCC-M42-WeeklyUpdate（可改时间，如周五下午晚一点）。

二、长协定价计算器（价格台 -> 长协定价）
  - 指数基准：ICI-4（Argus/Coalindo 印尼 4,200 GAR 周）/
    M42（McCloskey 印尼 4,200 GAR FOB 周）/ 两者平均
  - 输入 LAYCAN 起始日期，选"前 X 期"（1/2/3/4），手填 Premium（美元/吨，可为负）
  - 算法：取 LAYCAN 起始日之前最近 X 个周五发布的周指数，平均后加 Premium，
    得到该船 FOB 实际价。ADJUSTMENT 按合同公式另算，不在计算器内。

三、趋势图 / 价格台
  - 价格目录新增"M42（印尼 4,200 GAR FOB，周）"，可在"添加价格"里勾选，
    与 ICI-4、Argus 各指数同图对比、看同比。
